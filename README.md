# 🏰 AI Village (自律型AIエージェント仮想村シミュレーション)

ブラウザ上の2Dドット絵の仮想村で、**10人の生成AI（LLM）住人たちが自律的に生活し、出会い、記憶を形成しながら、事件を通じて派閥や対立を創発させるマルチエージェント社会シミュレーション環境**です。

スタンフォード大学の「Generative Agents」アーキテクチャに着想を得て、**FastAPI × WebSocket × Phaser 3 × Google Gemini API** を統合したフルサイクル開発プロジェクトです。

---

## 🌟 主な機能 (Key Features)

* 🧠 **自律型エージェント思考コア (Autonomous Agent Brain)**
  * 各住人が固有の「性格」「職業」「目標」「記憶ストリーム（Memory Stream）」を保持。
  * Gemini API の Structured Outputs を活用し、**「本音の心の声（Inner Thought）」「発言（Dialogue）」「身振り・行動（Action）」** を型安全に同時生成。
* 🏰 **2Dドット絵の村マップ & 吹き出しUI (Phaser 3)**
  * 外部アセットへの依存なくスタンドアロンで動作する、プロシージャル生成のドット絵マップ（草原・小道・噴水・パン屋・薬草小屋・鍛冶屋・教会）。
  * 住人同士が接近すると立ち止まり、頭上にエモーションアイコンや漫画風吹き出しを表示。
* ⚡ **リアルタイム神経接続 (FastAPI × WebSocket)**
  * サーバー側で計算された世界状態・思考・会話を低遅延でブラウザへストリーミング配信。
* ⏱️ **タイムライン進行 & 時間加速システム**
  * 村の時間を `1x` 〜 `20x`（1日 約72秒）までUI上で自由に変更可能。
* 📢 **シナリオイベント駆動**
  * `scenario.json` に定義された10日間のタイムライン（小麦粉盗難、短剣の紛失、山火事、自警団の台頭、村長選挙など）が時刻に応じて自動発火し、住人たちの話題や関係性が動的に変化。
* ⚡ **神様介入モード (God Mode)**
  * プレイヤーが天変地異や奇跡、噂をテキストで村に投下できるUIを搭載。全住人がその異変を知覚して緊急議論を開始。

## 🏗️ システムアーキテクチャ

```text
[ ブラウザ画面 (フロントエンド) ]
  Phaser 3 / HTML5 Canvas + Vanilla CSS (Glassmorphism)
  - 2Dドット絵マップ描画 & キャラクター徘徊アニメーション
  - 頭上吹き出し・エモーション表示
  - 10人の住人ステータス切替 ＆ リアルタイム村ログ
      ▲
      │ WebSocket (ws://localhost:8001/ws) リアルタイム双方向通信
      ▼
[ バックエンド (Python / FastAPI) ]
  FastAPI (Uvicorn)
  ├─ World Engine
  │    ├─ 時間進行ループ (1x 〜 20x 加速)
  │    ├─ シナリオイベント監視 (scenario.json)
  │    └─ 遭遇マッチング & 会話セッション管理
  └─ Agent Brains (自律エージェント思考コア)
       ├─ Perception (知覚: 誰が近くにいるか、村の最新ニュース)
       ├─ Memory Stream (時系列の会話・出来事記憶)
       └─ Decision Loop (Google Gemini API / Structured Outputs)
```

## 🛠️ 技術スタック (Tech Stack)

| レイヤー | 採用技術 | 選定理由 |
|---|---|---|
| **フロントエンド** | JavaScript / Phaser 3 | 2Dゲームエンジンのデファクト。ドット絵マップやアニメーションを直感的に制御 |
| **スタイリング** | Vanilla CSS (Glassmorphism) | ダークモードとグラスモフィズム、ネオンアクセントによるサイバーファンタジーUI |
| **バックエンド** | Python 3.13 / FastAPI / Uvicorn | 非同期I/Oに強く、WebSocketとLLM呼び出しの並行処理に最適 |
| **パッケージ管理** | uv | 超高速なPythonパッケージマネージャ |
| **LLM / 頭脳** | Google Gemini API (`gemini-2.5-flash` / `gemini-1.5-flash`) | 高速レスポンスかつ低コスト。Structured Outputsによる型安全な意思決定 |
| **通信プロトコル** | WebSocket | サーバー側の時間進行・エージェントの思考・セリフを画面へ低遅延プッシュ配信 |

## 🚀 クイックスタート (Setup & Run)

### 必要要件
* Python 3.12+ (推奨: `uv`)
* Node.js 18+
* Google Gemini API Key ([Google AI Studio](https://aistudio.google.com/) で取得可能)

### 1. リポジトリのクローン
```bash
git clone https://github.com/EngineerTSUYOSHI/AI-Village.git
cd AI-Village
```

### 2. バックエンドのセットアップ
```bash
cd backend
# 依存関係のインストール (uv)
uv sync

# APIキーの設定
cp .env.example .env
# .env を開き、GEMINI_API_KEY を設定してください
# ※ 未設定時は完全無料のモックモードで自動起動します

# サーバー起動 (ポート 8001)
uv run uvicorn app.server:app --host 0.0.0.0 --port 8001 --reload
```

### 3. フロントエンドのセットアップ
別ターミナルを開き：
```bash
cd frontend
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev
```

ブラウザで **http://localhost:5174/** を開くとシミュレーション画面が表示されます。
